# Construct Connect

**Construct Connect** is a web platform that acts as an interface between construction workers and customers. It enables direct and instant communication, fostering a collaborative environment that simplifies project coordination, improves transparency, and enhances productivity in construction projects.

---

## Features

### For Workers
- **Profile Management:** Create and manage professional profiles with skills, experience, and availability
- **Job Discovery:** Find construction projects matching your expertise and location
- **Status Management:** Toggle work availability between active/inactive
- **Review System:** Build reputation through customer ratings and reviews

### For Customers
- **Worker Search:** Find skilled construction workers by profession, location, and ratings
- **Project Management:** Create and manage construction projects with detailed requirements
- **Direct Communication:** Contact workers directly through multiple channels
- **Budget Planning:** Set project budgets and timelines

### Platform Features
- **User Authentication:** Secure login/signup with mobile verification
- **Advanced Filtering:** Search workers by location, profession, status, and ratings
- **Responsive Design:** Works seamlessly across desktop and mobile devices
- **Real-time Updates:** Dynamic content loading and status changes

---

## 🛠 Technology Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Icons:** Font Awesome 6.0
- **Storage:** Local Storage (for demo purposes)
- **Styling:** Custom CSS with responsive design
